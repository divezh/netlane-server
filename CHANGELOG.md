# Changelog

## 0.6.2

- Графики «Ресурсы сервера» и другие графики статистики: подписи времени больше не наезжают друг на друга (лишние скрываются, за сутки — только время, за неделю — дата и время, дольше — дата), график занимает всю ширину карточки, отступ слева подстраивается под подписи шкалы.

## 0.6.1

- Релизы подписываются ключом владельца, которого нет на GitHub: обновлятор, установщик и команда ноды ставят комплект только с верной подписью `trusttunnel-dev.tar.gz.sig`; релиз без подписи панель не предлагает.
- Обновлятор не ставит версию старше установленной и сверяет версию внутри комплекта с тегом.
- Обновлятор больше не пишет от root в каталог панели: отчёт лежит в `/var/lib/netlane-update/report`, путь к базе стран не берётся из настроек панели.
- Сборка на Go 1.26.11: исправлены уязвимости стандартной библиотеки (HTTP/2, TLS, x509); в CI проверка `govulncheck` и `cargo audit`.
- Движок VPN: обновлены h2, rustls, rustls-webpki, webpki-roots и другие зависимости с известными уязвимостями.
- Ноды получают для каждого пользователя свой пароль: захват ноды не даёт доступа к главному серверу и другим локациям. Клиенты получат новые ссылки нод при обновлении подписки.
- «Безопасность → Сеансы»: где открыта панель и кнопка «Выйти на других устройствах»; сеанс заканчивается после 2 часов без действий.
- Лимит входа считает IPv6 по сети /64 и ограничивает общее число попыток в минуту.
- Журнал хранит события год.
- Резервные копии можно шифровать ключом age; панель показывает время последней копии и шифруется ли она.

## 0.6.0

- Сервер обновляется только из последнего релиза публичного репозитория divezh/netlane-server; токен GitHub больше не нужен.
- Установка без комплекта рядом со скриптом скачивает последний релиз без токена.
- Код сервера открыт; прежний канал divezh/netlane-updates больше не используется.
