# Флаги стран у клиентов

Панель показывает в списке пользователей флаг страны клиента. Страну определяет
GeoIP по адресу подключения — локальной базой на сервере. Панель не обращается к
внешним сервисам, поэтому адреса клиентов остаются на вашем сервере; CSP панели
(`img-src 'self'`) сторонние картинки и так запрещает.

## База

Используется **DB-IP Lite Country**: бесплатная база уровня страны, лицензия
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), учётная запись не нужна,
обновляется раз в месяц. Данные предоставлены [DB-IP](https://db-ip.com).

Файл по умолчанию — `geoip.mmdb` рядом с базой панели, то есть
`/var/lib/trusttunnel-admin/geoip.mmdb`. Другой путь задаётся полем `geoip_path`
в конфигурации панели.

База **необязательна**: если файла нет, панель работает как раньше и просто не
рисует флаги — в списке остаётся адрес клиента.

## Обновление

Установщик кладёт скрипт в `/usr/local/sbin/geoip-update` и включает месячный
таймер `trusttunnel-geoip.timer`, а при установке сразу скачивает базу, чтобы
флаги появились без ожидания. **Обновлятор делает то же самое**: сервер, который
обновлялся, а не устанавливался заново, иначе остался бы без скрипта, таймера и
базы — и без флагов вообще. Вручную:

```bash
geoip-update              # текущий месяц
geoip-update 2026-11      # конкретный месяц
systemctl start trusttunnel-geoip.service
```

Если файла базы нет, панель скачивает её сама при запуске: пять мегабайт с
`download.db-ip.com`, не дольше тридцати секунд, и только когда файла нет.
Неудачная загрузка не мешает панели подняться — она просто продолжит работать
без флагов, а в «Работоспособности» появится пункт «База стран» с объяснением.
Так флаги появляются после обычного обновления, без отдельной команды на сервере.

Загрузка идёт с `download.db-ip.com`. Файл заменяется атомарно, поэтому панель
читает базу без перезапуска. Если загрузка не удалась, установка не считается
сломанной: панель продолжит работать без флагов, а таймер попробует снова.

## Флаги

Картинки — PNG из [flag-icons](https://github.com/lipis/flag-icons) (MIT):
500 файлов в двух размерах, 160 КБ. Лежат в `web/flags/` и отдаются самой панелью
по `/flags/<код>.<20|40>.png`; тот же набор используется в Windows-клиенте.

Эмодзи-флаги для этого не годятся: они собираются из региональных индикаторов, а
в Windows нет шрифта с их флагами, и система показывает «PL» вместо 🇵🇱.

## Что видно в интерфейсе

- клиент в сети — флаг страны и адрес подключения;
- клиент не в сети — флаг по последнему известному адресу, приглушённый;
- адреса нет или база его не знает — прочерк.
