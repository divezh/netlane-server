# Снимки интерфейса

`admin-overview.png` — рабочий веб-интерфейс с тестовыми ответами API, без данных production. Источник: `scripts/test-web-presence.mjs`, файл `artifacts/overview-readme.png`. Для его создания задайте `TT_CAPTURE_README=1` перед запуском теста.

Снимок делается одним кадром в окне высотой со всю страницу: фиксированная боковая панель занимает всю высоту изображения. Обычный full-page захват длинной страницы оставляет её высотой с исходное окно браузера.

После изменения интерфейса выполните [браузерную проверку](../../docs/WEB_QA.md), просмотрите результат и обновите снимок. Не используйте рабочие ссылки подписок, токены и имена пользователей.
